# 🚀 Rover Initialization System

Sistema básico para inicialização e verificação de telemetria inicial de um veículo explorador (Rover). O script executa o diagnóstico dos principais subsistemas antes do início das operações de campo.

---

## 📋 Descrição do Projeto

O **Rover Initialization System** é um módulo desenvolvido em Python responsável pela checagem de integridade e ativação dos subsistemas essenciais do Rover. Ao ser executado, ele valida:

- Ativação geral dos sistemas do Rover;
- Status operacional dos painéis solares;
- Nível de carga da bateria (capacidade máxima).

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Python 3.x
